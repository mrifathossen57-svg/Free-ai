Master Get Number Endpoint

Single endpoint for all 5 servers. Just pass range and get a number automatically.

Auto-Route (1–5)
POST {{ site_base }}/getnum
Request Headers
Content-Type: application/json
mauthapi: YOUR_USER_API_KEY
Request Body (JSON)
{
  "range": "26134XXX"
}
Success Response
{
  "meta": {
    "code": 200,
    "status": "success"
  },
  "data": {
    "range": "26134XXX",
    "full_number": "+447404333228",
    "server": "2 server"
  }
}
cURL Example
curl -X POST "{{ site_base }}/getnum" \
  -H "Content-Type: application/json" \
  -H "mauthapi: YOUR_API_KEY" \
  -d '{"range":"26134XXX"}'
Python Example
import requests

res = requests.post(
    "{{ site_base }}/getnum",
    headers={"mauthapi": "YOUR_API_KEY"},
    json={"range": "26134XXX"}
)
print(res.json())
