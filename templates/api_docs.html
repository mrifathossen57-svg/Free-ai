API Endpoints

Pass panel=1 (1 server), panel=2 (2 server), or panel=3 (3 server) via query string or JSON body. If a panel is turned OFF by Admin, the endpoint returns HTTP 503 while other active panels continue working.

POST {{ site_base }}/getnum

Allocate one number from a range on the selected panel.

Request body
{ "range": "26134XXX", "panel": "2" }
Response
{ "meta": { "code": 200, "status": "success" }, "data": { "panel": "2", "panel_name": "2 server", "full_number": "+447404333228" } }
  • Header: mauthapi: <your_user_api_key>
  • Optional panel values: "1" (1 server), "2" (2 server), "3" (3 server).
GET {{ site_base }}/liveaccess?panel=2

Recently-active services and live access ranges for the chosen panel.

Response
{ "meta": { "code": 200, "status": "ok" }, "data": { "services": [] } }
GET {{ site_base }}/my-numbers

Your allocated numbers (optionally filtered by ?panel=2), received OTPs, and current balance.

Response
{ "meta": { "code": 200, "status": "success" }, "data": { "numbers": [], "balance": 0.0 } }
GET {{ site_base }}/console?panel=2

Recent OTP hit logs for your account on the selected panel.

Response
{ "meta": { "code": 200, "status": "success" }, "data": { "hits": [] } }
