Master Get Number Endpoint

Single endpoint for all 5 servers. Pass range and your personal user API key — it checks active panels (1–5) and returns the first available number.

Auto-Route (1–5)
POST {{ site_base }}/getnum
Request Headers
Content-Type: application/json
mauthapi: YOUR_USER_API_KEY
Request Body (JSON)
{
  "range": "26134XXX"
}
Success Response
{
  "meta": {
    "code": 200,
    "status": "success"
  },
  "matched_panel": "2",
  "matched_panel_name": "2 server",
  "data": {
    "id": "a1b2c3d4e5f6",
    "panel": "2",
    "panel_name": "2 server",
    "range": "26134XXX",
    "full_number": "+447404333228",
    "country": "United Kingdom"
  }
}
cURL Example
curl -X POST "{{ site_base }}/getnum" \
  -H "Content-Type: application/json" \
  -H "mauthapi: YOUR_USER_API_KEY" \
  -d '{"range":"26134XXX"}'
Python Example
import requests

res = requests.post(
    "{{ site_base }}/getnum",
    headers={"mauthapi": "YOUR_USER_API_KEY"},
    json={"range": "26134XXX"}
)
print(res.json())

Live Access, OTP & Console Endpoints

Fetch live access ranges, allocated numbers, success OTPs, and console hits using your personal user API key.

GET {{ site_base }}/liveaccess

Returns active services and live ranges from the selected/active server.

GET {{ site_base }}/success-otp

Syncs and returns received OTP messages, OTP logs, and current balance.

GET {{ site_base }}/my-numbers

Syncs and returns your numbers, OTP messages, expiry timers, and balance.

GET {{ site_base }}/console

Returns live hits and active ranges across all enabled servers.
