POST {{ site_base }}/api/bridge/getnum

Allocate one number from a range — same as Get Number.

Request body
{ "range": "26134XXX" }
Response
{ "ok": true, "item": { "full_number": "+447404333228", "country": "United Kingdom", "operator": "EE" } }
  • Header: mauthapi: <your_api_key>
  • Returns allocated number details with expiry timer and rate info.
